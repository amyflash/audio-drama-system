# 极简广播剧系统

基于 FastAPI + Nuxt 3 的音频剧管理与播放系统。

## 系统架构

```
┌─────────────────────────────────────────────────────────────┐
│                      用户浏览器                               │
└─────────────────────────┬───────────────────────────────────┘
                          │
                          ▼
┌─────────────────────────────────────────────────────────────┐
│                  jwt-auth 服务 (8000)                        │
│                  - 用户认证                                   │
│                  - SSO 单点登录                              │
└─────────────────────────────────────────────────────────────┘
                          │
                          ▼ (登录成功后获取 token)
┌─────────────────────────────────────────────────────────────┐
│                  音频剧系统 (8001)                            │
│                  - 前端静态文件                               │
│                  - 后端 API                                  │
└─────────────────────────────────────────────────────────────┘
```

## 部署架构

- **jwt-auth**: 端口 8000，提供用户认证服务
- **音频剧系统**: 端口 8001，提供业务功能
- **SSO对接**: 音频剧系统验证 jwt-auth 签发的 token

## 快速启动

### 1. 配置环境变量

```bash
cd backend
cp .env.example .env
# 编辑 .env，配置 SSO_SECRET_KEY 与 jwt-auth 一致
```

### 2. 构建前端

```bash
# 开发模式（热重载）
./start-frontend.sh

# 或生产构建
./build-frontend.sh
```

### 3. 启动服务

```bash
# 启动后端（端口 8001）
./start-backend.sh

# 或一键启动（需先完成前端构建）
./start-all.sh
```

## 开发说明

| 脚本 | 用途 |
|------|------|
| `start-frontend.sh` | 前端开发服务器 (5173) |
| `start-backend.sh` | 后端服务 (8001) |
| `build-frontend.sh` | 构建前端并复制到后端 |
| `start-all.sh` | 一键启动完整系统 |
